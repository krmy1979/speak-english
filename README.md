# מדברים אנגלית

אפליקציה לתרגול דיבור באנגלית עם משפטים מהיום־יום.

## איך מפעילים
פתח את `index.html` בכרום או באדג' (לחיצה כפולה, או קליק ימני ← Open with).
בפעם הראשונה שתלחץ על המיקרופון, אשר לדפדפן גישה למיקרופון.
זיהוי הדיבור צריך חיבור לאינטרנט.

## מה יש באפליקציה
- **מסלול** – 300 משפטים ב־3 רמות (מתחיל, בינוני, מתקדם), 10 שיעורים בכל רמה. שיעור נפתח אחרי שמסיימים את הקודם (7 מתוך 10 משפטים בשליטה), ובסוף כל רמה מקבלים תעודה.
- **האימון של היום** – 10 משפטים: קודם חזרות שהגיע זמנן, ואחר כך משפטים חדשים מהשיעור שלך.
- **שיחות** – 6 שיחות תפקידים (בית קפה, שכן חדש, ראיון עבודה, טלפון, מלון, חנות). הצד השני מדבר ואתה עונה בקול.
- **חזרה חכמה** – כל משפט חוזר בדיוק לפני שנשכח: אחרי יום, 3 ימים, שבוע, שבועיים, חודש וחודשיים. טעות מחזירה אותו להתחלה.
- **מבטא** – 8 יחידות לצלילים שקשים לדוברי עברית (TH, W/V, אִי ארוכה/קצרה, אַ/אֶ, R, H, סיומת ED). בכל יחידה: הסבר, זוגות מילים, תרגול שמיעה ודיבור ומשפט אתגר.
- **האזנה** – שומעים משפט ובוחרים מה הפירוש. מאמן את האוזן.
- **תיקון הגייה** – כל מילה שלא נשמעה טוב מסומנת באדום, עם מה שהמערכת שמעה במקומה, איך המילה נשמעת בעברית, טיפ לתיקון (TH, W/V, R, אִי ארוכה, אותיות שקטות, סיומות ED/ING) וכפתור לתרגל רק את המילה.
- הקלטה עצמית והשוואה לקול המקורי, לחיצה על מילה כדי לשמוע אותה, מצב אתגר, קול אמריקאי או בריטי.
- יעד יומי של 10 משפטים, רצף ימים ומונה משפטים שאתה שולט בהם.

## מבנה הפרויקט
```
speak-english/
├── index.html      מבנה המסכים
├── css/style.css   עיצוב (בהיר וכהה)
├── js/data.js      נושאי המשפטים והשיחות
├── js/course.js    הרמות, השיעורים ויחידות המבטא
├── js/app.js       הלוגיקה: הקראה, זיהוי דיבור, ציון, התקדמות
└── README.md
```

## הוספת משפטים
ב־`js/course.js`, בתוך השיעור הרצוי (ב־items או extra), מוסיפים שורה:
```js
["English sentence.", "המשפט בעברית", "טיפ (אפשר להשאיר ריק)"],
```

ההתקדמות נשמרת בדפדפן במחשב הזה.
