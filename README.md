# מדברים אנגלית

אפליקציה לתרגול דיבור באנגלית עם משפטים מהיום־יום.

## איך מפעילים
פתח את `index.html` בכרום או באדג' (לחיצה כפולה, או קליק ימני ← Open with).
בפעם הראשונה שתלחץ על המיקרופון, אשר לדפדפן גישה למיקרופון.
זיהוי הדיבור צריך חיבור לאינטרנט.

## מה יש באפליקציה
- **משפטים** – 78 משפטים ב־11 נושאים, ו"10 של היום" שמתחלפים כל יום.
- **שיחות** – 6 שיחות תפקידים (בית קפה, שכן חדש, ראיון עבודה, טלפון, מלון, חנות). הצד השני מדבר ואתה עונה בקול.
- **חזרה** – משפטים שקיבלו "כמעט" או "צריך עוד תרגול" נאספים לכאן.
- **האזנה** – שומעים משפט ובוחרים מה הפירוש. מאמן את האוזן.
- הקלטה עצמית והשוואה לקול המקורי, לחיצה על מילה כדי לשמוע אותה, מצב אתגר, קול אמריקאי או בריטי.
- יעד יומי של 10 משפטים, רצף ימים ומונה משפטים שאתה שולט בהם.

## מבנה הפרויקט
```
speak-english/
├── index.html      מבנה המסכים
├── css/style.css   עיצוב (בהיר וכהה)
├── js/data.js      כל המשפטים והשיחות – כאן מוסיפים תוכן
├── js/app.js       הלוגיקה: הקראה, זיהוי דיבור, ציון, התקדמות
└── README.md
```

## הוספת משפטים
ב־`js/data.js`, בתוך הנושא הרצוי, מוסיפים שורה:
```js
["English sentence.", "המשפט בעברית", "טיפ (אפשר להשאיר ריק)"],
```

ההתקדמות נשמרת בדפדפן במחשב הזה.
