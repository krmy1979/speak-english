# 🚗 ירין על ההגה

משחק מכוניות לימודי לילדים מגיל 3. הוא עובד בדפדפן של הטלפון ואפשר להוסיף אותו למסך הבית של האייפון כמו אפליקציה.

## 🔗 קישור למשחק
**https://krmy1979.github.io/speak-english/yarin/**
(הקבצים נמצאים במאגר speak-english בתיקייה `yarin`)

## מה יש במשחק
| מסך | מה לומדים |
|------|-----------|
| 🛠️ **מוסך** | בוחרים רכב: מכונית, משאית, מערבל בטון, כבאית, אמבולנס או מכונית מרוץ, ושומעים את השם שלו |
| 🚦 **רמזור** | אדום עוצרים, ירוק נוסעים (בטיחות בדרכים) |
| 🧱 **אתר בנייה** | ספירה מ־1 עד 5: בונים בית מלבנים ועוצרים במספר הנכון |
| 🔥 **הצלה** | ספירה ועזרה לאחרים: מכבים להבות עם הכבאית ושולחים אמבולנס |
| 🫧 **שטיפת צבעים** | צבעים: מוצאים את הדלי בצבע שהקריין מבקש, והרכב נצבע |

כל תחנה שמסיימים נותנת ⭐ כוכב. אין פסילות ואין שעון, יש רק עידוד.
קריין בעברית מקריא הכול, כי ילדים בגיל הזה עדיין לא קוראים.

## איך מריצים במחשב
1. פותחים את התיקייה ב־VS Code.
2. לוחצים לחיצה ימנית על `index.html` ובוחרים **Open with Live Server** (צריך את התוסף Live Server).
   אפשר גם פשוט ללחוץ פעמיים על `index.html`.
3. לבדיקה מהירה של מסך מסוים מוסיפים לכתובת: `#garage`, `#map`, `#traffic`, `#build`, `#fire` או `#wash`.

## איך שמים באייפון
1. פותחים ב־Safari באייפון את הקישור שלמעלה.
2. לוחצים **שיתוף**, ואז **הוסף למסך הבית**. הסמל של ירין יופיע על המסך.

> 🔊 הקריין משתמש בקול העברי שמובנה באייפון. אם אין קול, צריך לבדוק שהמתג השקט בצד הטלפון כבוי.

## מבנה הקבצים
```
yarin-al-hahege/
├── index.html        ← הדף הראשי
├── style.css         ← כל העיצוב
├── manifest.json     ← הגדרות "אפליקציה" למסך הבית
├── js/
│   ├── vehicles.js   ← ציורי הרכבים (SVG מקורי)
│   ├── sound.js      ← קריין עברי + אפקטים (צופר, סירנה, מים)
│   └── game.js       ← כל המסכים והתחנות
└── icons/            ← הסמל של המשחק בכל הגדלים
```

## שינויים קלים
- **שינוי שם הילד:** ב־`js/game.js`, בשורה `const PLAYER_NAME = 'ירין';`
- **שינוי טווח הספירה:** מחפשים את `rand(2, 5)` ב־`game.js`.

## ⚖️ הערות משפטיות
- כל הדמויות והציורים מקוריים. אין שימוש בדמויות מסדרות או מסרטים (למשל "מכוניות", "פאו פטרול", "רובוקאר פולי", "בוב הבנאי").
- על האמבולנס מצויר **לב אדום**. הצלב האדום ומגן דוד אדום הם סמלים שמוגנים בחוק, ואסור להשתמש בהם.
- הקולות נוצרים בקוד, ואין במשחק קבצי קול או מוזיקה של אחרים.
- לפני שמפרסמים בחנות האפליקציות צריך לחפש שם את השם "ירין על ההגה" ולוודא שהוא פנוי.
